Follow these steps in order to install Starcel manually. After any step, you can
switch back to the automatic installer by running `starcel install` (or
`starcel install-dev` for the dev setup).

Required for everyone:
  1. Python 3.9.x — see https://www.python.org/downloads/release/python-3913/
     Download the "Windows installer (64-bit)" and check "Add python.exe to PATH"
     before clicking Install Now.
  2. Run: pip install 'starcel[alpha]'
  3. Run: starcel install
  4. The UE4 prerequisites step below.

Optional for developers:
  5. Visual Studio 2019 Community with the listed components.
  6. UE4.27.2 from the EpicGames GitHub repo (requires linking your Epic
     Games account to GitHub first).
