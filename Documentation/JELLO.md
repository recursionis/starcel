# Jello

- Python wrapper around Jellyfish, a fork of Dennis Mitchell's Jelly tacit language; maps English-like names (`iota`, `prior`, `scan`, `maxr`, `add1`) to Jelly atoms (`R`, `ṕ`, `\`, `Ṁ`, `‘`) and builds combinator-tree decompositions of monadic, dyadic, triadic, and n-adic chains.
- Lives at `Content/Scripts/nd_table/jello/`. Key files in `src/`: `jello.py` (REPL entry), `draw.py` (combinator-tree construction), `grid.py` (grid + CCS linearization), `tokens.py` (name to atom table), `algorithm.py` (chain-rewrite advisor), `utils.py` (Chain/Quick/Separator dataclasses), `arity_notation.py` (arity rendering), `test.py` (unit tests). The list is not exhaustive.
- Source brief for the BBBB investigation lives in the jello tree at `Content/Scripts/nd_table/jello/bbbb_research_brief.html` (38 decisions, Q1 to Q14).
- Interactive REPL for tacit Jelly chains using English-like token names; name to atom translation through `tokens.py` so chains read as `iota flat < prior : + * r . scan maxr add1` instead of `RF<ṕð+×ṛµ\Ṁ‘`.
- Builds the combinator-tree decomposition of a chain (monadic, dyadic, triadic, n-adic) via instrumented emit trace; linearizes the tree to a CCS string (e.g. `BBBB` for the expression of study); monadic CCS and dyadic CCS reported separately.
- Algorithm advisor surfaces equivalence-lattice rewrites between chains; unit tests pin down arity inference and CCS linearization.
- REPL entry: `python jello.py` from `src/`.
- Test suite: `PYTHONIOENCODING=utf-8 python test.py` from `src/` (the encoding env var is required on Windows for the non-ASCII atoms).
- Quick check: `iota flat < prior : + * r . scan maxr add1` on `[2,4,3]` evaluates to `4`; both monadic and dyadic CCS come out as `BBBB`.
- Sibling documents in `Documentation/`: `jello_ccs_analysis.html` (deep analysis of the CCS counting rule, instrumented emit trace, 7-probe table, empirical rule `|CCS|_B = k + 2`), `jello_decisions.md` (the 38-entry decision log D1 to D38 from the BBBB workflow).
- In the jello source tree: `bbbb_research_brief.html` is the original source brief and supersedes the two sibling documents above when they disagree.
- BBBB investigation closed: the expression of study `iota flat < prior : + * r . scan maxr add1` was traced through 8 emitted combinators (4 visible in CCS), cross-checked against a 7-probe table (P1 to P7), and the empirical rule `|CCS|_B = k + 2` (k leading monads, two separators, non-empty `.`-tail with at least one monad) was established. Fourteen open questions (Q1 to Q14) remain — see `jello_ccs_analysis.html` for the counting-rule proof attempt and `bbbb_research_brief.html` for the full decision log.
